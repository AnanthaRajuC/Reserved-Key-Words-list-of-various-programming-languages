# Swift Reserved Words

The set of reserved words below is used to build up the basic instructions of Swift; you cannot use them as identifiers (like variable or function names), unless escaped using backticks in some cases.

- A  
  - associatedtype  

- C  
  - class  

- D  
  - deinit  

- E  
  - enum
  - extension  

- F  
  - fileprivate

## Notes

- Swift allows using keywords as identifiers if wrapped in backticks: `` `class` ``
- Keywords are grouped by usage context (declarations, statements, expressions, etc.)
- `#` keywords are compiler directives and special literals
