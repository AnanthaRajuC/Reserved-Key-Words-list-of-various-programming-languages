# Julia Reserved Words

The set of reserved words below is used to build up the basic instructions of Julia; you cannot use them as identifiers (like variable or function names).

## Keywords

- A  
  - abstract
  - as

- B  
  - begin
  - break  

- C  
  - catch
  - const
  - continue  

- D  
  - do  

- E  
  - else
  - elseif
  - end
  - export  

- F  
  - false
  - finally
  - for
  - function  

- G  
  - global  

- I  
  - if
  - import
  - in  

- L  
  - let
  - local  

- M  
  - macro
  - module  

- N  
  - nothing  

- Q  
  - quote  

- R  
  - return  

- S  
  - struct  

- T  
  - true
  - try  

- U  
  - using  

- W  
  - while  

---

## Reserved for Future Use

These words are reserved and may be used in future versions of Julia:

- A  
  - abstracttype  

- B  
  - bitstype  

- I  
  - immutable  

- P  
  - primitive  

- T  
  - type  

---

## Notes

- Julia keywords are relatively minimal compared to other languages
- `true`, `false`, and `nothing` are built-in constants
- Julia also supports powerful macros (`macro`) and metaprogramming features
