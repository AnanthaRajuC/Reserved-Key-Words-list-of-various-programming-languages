# Scala Reserved Words

The set of reserved words below is used to build up the basic instructions of Scala; you cannot use them as identifiers (like variable or function names).

## Keywords

- A  
  - abstract  

- C  
  - case
  - catch
  - class  

- D  
  - def
  - do  

- E  
  - else
  - extends  

- F  
  - false
  - final
  - finally
  - for
  - forSome  

- I  
  - if
  - implicit
  - import  

- L  
  - lazy  

- M  
  - match  

- N  
  - new
  - null  

- O  
  - object
  - override  

- P  
  - package
  - private
  - protected  

- R  
  - return  

- S  
  - sealed
  - super  

- T  
  - this
  - throw
  - trait
  - try
  - true
  - type  

- V  
  - val
  - var  

- W  
  - while
  - with  

- Y  
  - yield  

---

## Notes

- Scala does not formally separate keywords into strict/weak like Rust, but some are **context-sensitive** (e.g., `implicit`, `lazy`)
- All listed keywords are reserved in standard Scala syntax
- Scala allows symbolic method names (e.g., `+`, `::`) which behave differently from keywords
