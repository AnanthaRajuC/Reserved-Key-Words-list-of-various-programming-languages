# Groovy Reserved Words

The set of reserved words below is used to build up the basic instructions of Groovy; you cannot use them as identifiers (like variable or function names).

## Keywords

- A  
  - abstract
  - as
  - assert  

- B  
  - break  

- C  
  - case
  - catch
  - class
  - const
  - continue  

- D  
  - def
  - default
  - do  

- E  
  - else
  - enum
  - extends  

- F  
  - false
  - final
  - finally
  - for  

- G  
  - goto  

- I  
  - if
  - implements
  - import
  - in
  - instanceof
  - interface  

- N  
  - new
  - null  

- P  
  - package
  - private
  - protected
  - public  

- R  
  - return  

- S  
  - static
  - strictfp
  - super
  - switch  

- T  
  - this
  - throw
  - throws
  - trait
  - true
  - try  

- V  
  - var
  - void
  - volatile  

- W  
  - while

## Contextual / Groovy-Specific Keywords

These keywords have special meaning in Groovy-specific contexts.

- A  
  - as  

- D  
  - def  

- I  
  - in  

- T  
  - trait  

---

## Notes

- Groovy is largely compatible with Java, so many keywords are shared
- `def` is commonly used for dynamic typing in Groovy
- Some Java reserved words like `goto` and `const` are unused but still reserved
