# Dart Reserved Words

The set of reserved words below is used to build up the basic instructions of Dart; you cannot use them as identifiers (like variable or function names), depending on their category.

## Reserved Keywords

These keywords are **always reserved** and cannot be used as identifiers.

- A  
  - abstract
  - as
  - assert
  - async
  - await  

- B  
  - break  

- C  
  - case
  - catch
  - class
  - const
  - continue  

- D  
  - default
  - do
  - dynamic  

- E  
  - else
  - enum
  - export
  - extends  

- F  
  - false
  - final
  - finally
  - for  

- G  

- I  
  - if
  - implements
  - import
  - in
  - interface
  - is  

- L  

- M  
  - mixin  

- N  
  - new
  - null  

- O  

- P  
  - part  

- R  
  - rethrow
  - return  

- S  
  - static
  - super
  - switch  

- T  
  - this
  - throw
  - true
  - try
  - typedef  

- V  
  - var
  - void  

- W  
  - while
  - with  

- Y  
  - yield

## Built-in Identifiers

These have special meaning but **can be used as identifiers in some contexts**.

- A  
  - async*
  - await*  

- C  
  - covariant  

- D  
  - deferred  

- F  
  - factory  

- G  
  - get  

- H  
  - hide  

- O  
  - of
  - on  

- S  
  - set
  - show
  - sync*
  - sync  

---

## Notes

- **Reserved keywords**: Always restricted (e.g., `class`, `if`, `return`)
- **Built-in identifiers**: Contextual (e.g., `get`, `set`, `factory`)
- Dart uses `async`, `await`, and `yield` for asynchronous programming
