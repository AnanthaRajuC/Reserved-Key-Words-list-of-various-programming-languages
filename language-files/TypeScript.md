# TypeScript Reserved Words

The set of reserved words below is used to build up the basic instructions of TypeScript; you cannot use them as identifiers (like variable or function names), depending on their category.

## Reserved Keywords

These keywords are **always reserved** and cannot be used as identifiers.

- A  
  - abstract
  - any
  - as
  - async
  - await  

- B  
  - boolean
  - break  

- C  
  - case
  - catch
  - class
  - const
  - continue  

- D  
  - debugger
  - declare

  - delete
  - do  

- E  
  - else
  - enum
  - export
  - extends  

- F  
  - false
  - finally
  - for
  - from
  - function  

- G  
  - get  

- I  
  - if

  - import
  - in
  - instanceof
  - interface
  - is  

- K  
  - keyof  

- L  
  - let  

- M  
  - module  

- N  
  - namespace
  - never
  - new
  - null
  - number  

- O  
  - object  

- P  
  - package

## Notes

- TypeScript builds on JavaScript, so many keywords come from ECMAScript
- **Reserved keywords**: Always restricted (e.g., `class`, `const`, `return`)
- **Contextual keywords**: Only special in certain syntax (e.g., `keyof`, `readonly`)
- Includes additional type-related keywords not found in plain JavaScript
